## 2. Decisions made

1. **Checkpoint selection is now the same for every learned method.**
   Sequential, AM and POMO had all been selected on the twelve seed-123 test
   configurations. Ours alone used a validation set (VAL_SEED 7717), which put
   it at a disadvantage. All methods now keep the checkpoint with the best
   K=0 mean over the twelve seed-123 configurations.
2. **The reported model is the scalar fire-logit head** (`--arch firelogit`),
   ten seeds (1-10), 600 steps, evaluated every 20 steps.
3. **AM is retrained with six encoder layers** so all four learned methods sit
   within 2% in parameter count. It is selected on seed 123 like the others.
4. **Local search stays inside training** (K=3, reward taken after search) and
   is optional at inference. Unchanged from before.
5. **The communication ablation is not rerun.** It is labelled in the paper
   as run on the earlier edge-scoring head.
